## Terminal Skills

- Navigate folders with `pwd`, `cd`, and `cd ..`
- Create folders and files with `mkdir` and `New-Item`
- List folder contents with `ls`
- Open projects in VS Code with `code .`

## Git & GitHub

- Understand the difference between Git (local) and GitHub (online)
- Create a repository from scratch locally with `git init`, then connect and push it to GitHub
- Clone an existing GitHub repository with `git clone`
- Run the full **add → commit → push** cycle across separate repositories
- Understand the three file states: **working → staged → committed**
